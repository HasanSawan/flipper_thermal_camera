This browser has no Web Serial or Web Bluetooth. Open this page in Chrome, Chromium or Edge (Firefox and Safari support neither). On Fedora: sudo dnf install chromium. The Demo button works in any browser.
Bluetooth: on the Flipper press Left/Right to Bluetooth, then OK. Here, pick the device whose name starts with Flipper. The first time, the Flipper shows a PIN: type it into the pairing prompt of your computer. Bluetooth is much slower than USB (about 1–4 frames per second). The Flipper takes one Bluetooth connection at a time: if its phone app is connected, close the app first.
