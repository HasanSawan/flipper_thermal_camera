# Changelog

v1.2:

- Human mode: body-temperature screening estimate with a calibratable body offset, NORMAL, HIGH and LOW status, LED colours and vibration alerts, and a not-a-medical-device disclaimer
- Bluetooth streaming mode: the same live stream as USB, over Bluetooth LE to the browser viewer
- Spot mode: OK saves the temperature graph as CSV together with the still image
- Graph Log setting: continuously appends the spot history to a CSV log for long monitoring
- Factory Reset and Exit App in Settings
- Numbered view modes
- Viewer: save the last 10 s to 5 min as video, CSV or raw data; start and stop recording and save the spot graph on the SD card remotely
- The threshold now applies only in the Threshold view
- More reliable exit when holding Back
- Fixed: CSV export lost the minus sign for values between -1 and 0 degrees

v1.1:

- Spot meter mode with a large readout and a temperature-history graph
- USB streaming mode with a browser viewer (Web Serial): colour image, measurement points and boxes, graphs, histogram, isotherm, PNG, CSV, video and raw saving, remote control of the settings
- Up and Down now adjust the setting of the current mode, shown in an on-screen badge
- New settings: Gamma, EQ Strength, Contour Step, Spot Size, Graph Time
- About screen
- Contour lines are now at fixed temperatures and no longer move when the range changes
- Left and Right are ignored while recording

v1.0:

- First release: live dithered image, max, centre and min readout, five render modes, thresholds, PNG, TIFF and CSV stills, PNG-sequence and raw recording, settings menu
